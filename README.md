# Studio Kit

> Author: kit-writer · claude-sonnet-5-5 · medium · 2026-10-20

An AI game studio setup for Roblox games. Clone it into every new game. It holds one shared rulebook for Claude Code and Codex, the roles, skills, job templates and a knowledge skeleton.

## Three layers

| Layer | Holds | Changes when |
| --- | --- | --- |
| Kit (universal) | Rules, orchestration, roles, skills, templates | A lesson applies to every game |
| Game profile (per game) | `knowledge/design/game-profile.md`, decisions, game content | The owner shapes this game |
| Project overlays | Per-game adjustments made by `/integrate` | The kit updates (owner approves) |

## Start a new game

1. Clone the kit folder and rename it.
2. Fill `knowledge/design/game-profile.md` and `rules/owner-profile.md`.
3. Run `python tools/sync_harness.py` (generates `.claude/` and `.codex/`).
4. Open the folder in Claude Code or Codex.

## How the studio works

- **Lead:** the first chat talks to the owner, sizes jobs, routes work and reports.
- **Job sizes:** S (one agent, no paperwork), M (one output: job card + brief), L (several crafts: full job folder).
- **Gates:** G1 brief (M, L), G2 first samples (L), G3 final look (all visible work). Only the owner passes a gate.
- **Tickets:** agents ask each other for work inside an approved brief, logged in the job ledger.
- **Statuses:** proposed, approved, working, blocked, needs-decision, done, failed, cancelled. Problems go up one level.
- **Decision digest:** one batch of owner questions per turn, each with a recommendation and a default.

## Folder map

| Path | Holds |
| --- | --- |
| `AGENTS.md`, `CLAUDE.md` | Shared rulebook; Claude entry point |
| `rules/` | Company rules, owner profile, harness profiles |
| `.agents/` | Canonical roles and skills |
| `.claude/`, `.codex/` | Generated by `tools/sync_harness.py` (committed, never hand-edited) |
| `templates/jobs/` | Job card, brief, beat sheet, ledger, digest, status block |
| `knowledge/` | Index, design records, jobs, inbox, reference |
| `tools/` | Gate, context packet, sync tools |
