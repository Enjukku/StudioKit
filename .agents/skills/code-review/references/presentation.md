# Player-facing truth in code

A correct server can still lie to players through the client: a coin burst before the sale is accepted, a counter that says the player cannot afford what they can, a reveal that hints at a rarer egg than the roll, a danger ring smaller than the hit, another player's effect shaking my camera. The craft books set what each moment must look and sound like; the architect's presentation contract says what starts it, for whom and from which data; the builder wires it. My job is the code: **when** each layer plays, **for whom**, **from which data**, and **what a failed request shows**. I never judge the look.

Where the rules live (I check against them, I do not restate them): `architecture` R-05, R-13, R-19 to R-22 and `references/presentation-contract.md` (the event rows I review against: layer, source, payload, per viewer, comfort, rate, information, truth); `engineering-craft` EC-17 to EC-24 and `references/presentation.md` §1-§9 (the builder's feedback stack sheet, wiring, test hooks and debug log); `platform-policy` § A for paid random items. Use this page when the change plays effects, sound, UI motion, counters, reveals or camera moves (harm order areas 3 and 6), and for any change that connects animation, tween or effect handlers or touches the test hooks (PT-18, PT-19: harm areas 2 and 3).

## 5. Screening patterns (screening aids, not proof)
Run with the Grep tool (ripgrep syntax) on the files the manifest lists, with the working tree at the candidate revision; or revision-bound: `git grep -n -E '<pattern>' <candidate> -- <paths>`. Both forms take the patterns below unchanged: `git grep -E` has no `\d` (it matches the letter d, with no error), so digits are written `[0-9]`; `\s` and `\b` work in both. Both read one line at a time: a call split over several lines is missed. A hit is a place to read; a miss proves nothing.

Patterns, copied exactly (one per line; S3 is two searches; S5 points to the builder's book, never copied):
```text
S1  :(FireServer|InvokeServer)\(|OnClient(Event|Invoke)
S2  CurrentCamera|FieldOfView|ColorCorrectionEffect|BlurEffect|BloomEffect|BindToRenderStep
S3  step 1 (files): TweenService|FieldOfView|[Ss]hake|ColorCorrectionEffect|LocalTransparencyModifier      step 2 (files): ReducedMotionEnabled|reducedMotion\(|shakeScale\(|reduceFlashes\(|screenEffects\(|clarity\(      candidates: in step 1, not in step 2
S4  FlipbookStartRandom\s*=\s*true|math\.random|Random\.new|:Next(Number|Integer)\(
S5  the literals grep of engineering-craft/references/presentation.md §10 and the asset-id grep of sound-design/references/review.md R-44, run on the changed files
S6  AdjustSpeed\(|TimeScale\s*=
S7  task\.(wait|delay)\(\s*[0-9]*\.?[0-9]+          only in files that also call Emit or Play
S8  Visible\s*=\s*not\b|Transparency\s*=\s*1\s*-|TweenInfo\.new\(.*-1\s*[,)]
S9  GetMarkerReachedSignal|KeyframeReached|\.(Completed|Touched|Stopped|Ended|DidLoop)\b
S10 TestHooks|IsStudio\(
```
