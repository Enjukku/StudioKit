# Evidence library

- `sound-emotion-reference.md` is a verbatim copy of the full library (v2, 2026-10-10): elements E-, recipes, methods M-, qualities Q-, rules S-01..S-234, gaps G-, DO NOT USE D-, contested verdicts, merge log and all sources with URLs. Every ID in this skill traces back to it.
- Open it only to check a source or study detail, settle a dispute between rules, or update rules. Never load it for routine design work.
- Add evidence: append a row with the next free ID and an evidence level (study / practice / inference; leads never above inference), tag every number (M)/(X)/(O)/(=)/(P), add the source to Sources, and log any change to an existing rule in the Merge log with the reason (newer and better-sourced evidence wins).
- Then update the one reference file that holds that ID (or SKILL.md for core rules and guardrails), keeping each fact in exactly one file, and re-run `evals/briefs.md`.
