# Lessons: first progression jobs (worked examples, hidden evals)

## What worked
- Tune in a scratch harness first, then write the clean model once.
- Discrete 1-second ticks for long incremental runs keep exact reports small; continuous exact mode with exponential prices does not.
- One stress run per wall type made walls visible (now built into the simulator for every policy).
- Compare options under the same policy and horizon; re-simulate option combinations too (two good fixes together removed the last soft wall).
- Exact duels for any boss near a TTK = TTD tie: the simultaneous-hit rule decides the boss, and engineering must copy it.
- The hard-wall report ("affordable but locked") shows "coins with nothing to buy" directly; a skill profile with extra attack delay turned a near tie into the reported symptom.
- Reading the local docs mirror settled paid-random and experiment questions without guessing.

## What failed first
- A fixed rebirth requirement collapses later runs (119 → 8 seeds per reset by day 22).
- Old content paying more XP per second than the new zone made model players skip the zone: a dominant-shortcut check belongs in every RPG review.
- Float mode hid a rounding-absorbed purchase in the ledger (now booked as float_rounding).
- In hidden evals, steps the books describe were skipped under pressure: reward ledger and four clocks, the full odds rule, a written engineering brief, re-simulating the proposed change. The self-checks now list them.
