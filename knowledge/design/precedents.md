# Precedents: accepted work that shows what this game is

Filed at every job close (`orchestration` skill §9). One row per accepted artifact the owner approved at G3 (or G2 for a direction-setting proof). The **Craft** cell names the kit roles of that craft (stems of `.agents/roles/*.md`, comma-separated, e.g. `vfx-designer, sound-designer`): the context packet's `--role` block and the `SubagentStart` hook list each role's newest rows from it, so agents read the rows of their craft before they start. The art bible's "allowed variation" keeps new work from copying old work.
