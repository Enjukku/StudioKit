## 4. What worked (habits that visibly prevented rework)

- Independent reviewer before merge found High issues the builder missed (stage cover stale hide ed0c842f; F8 776720c0; pile-sweep release 5489c26d; instant-credit teleport hole 368d56dc; mountain bedrock f92651c1).
- Default-OFF switches with Studio attribute A/B arms: unified contact (893fbca2), B1 lanes (9aa7b8c9), bigStress (c8e2668b), D2 far-hide and debris stayed off until measured, so none shipped as a regression.
