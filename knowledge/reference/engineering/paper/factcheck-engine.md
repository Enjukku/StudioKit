- Verdicts: confirmed, corrected, partly, unverified, contradicted, outdated. "confirmed" always names the source.
- Studio MCP was not used: `list_roblox_studios` returned no connected Studio on 2026-10-21, so nothing here is "MCP-verified". Two points need a Studio probe (see Questions).

## 3. Use in skills (safe to state as fact, with the stated source)

1. Generalized iteration: `1..#t` in order then unordered; changing keys other than the current one is unspecified; appending at `#t+1` to a dense array is guaranteed to be visited (luau.org/syntax). Policy "do not mutate a traversed dictionary" is sound.
2. `const` stops reassignment of the binding, never mutation of the value; use `table.freeze` for the value (luau.org/syntax; Roblox docs say the same). Do not claim it works in Roblox until probed (see Do not use).
3. `table.create(n)` reserves array space only (not dictionary space) and returns an empty table when no fill value is given; `table.clear` keeps capacity; `table.clone` is shallow, keeps the metatable, and is unfrozen; `table.freeze` is in place, shallow, and raises an error on an already-frozen table, so check `table.isfrozen` first.
4. `ipairs`, `pairs` and generalized iteration cost about the same; `ipairs` stops at the first nil. Do not cache methods in locals; `getfenv`, `setfenv` and `loadstring` disable import optimizations; `string.byte(s)` beats `s:byte()` because builtins are fastcalled only as direct calls.
5. Avoid temporary tables and userdata in tight loops (allocator and GC assists).
6. `any` skips checks; `unknown` must be refined; a cast on a multi-value expression keeps only the first value; `assert`, type tests, equality and truthiness refine types.
7. Native code: Studio docs say `Script`s on the server, `--!native` or `@native`, numeric work best, mistyped arguments and `getfenv`/`setfenv` can de-optimize, a breakpoint disables native for that function, the top-level scope is not usefully compiled, and the per-function and per-module limits are 64K instructions per block, 32K blocks per function, 1M instructions per module. Always measure with and without.
8. `UseNewLuauTypeSolver` is Not Scriptable (set it in the Workspace properties or a plugin). As of 2025-11-20: new solver is on for nocheck/nonstrict; a project with strict scripts stays on the old solver unless `Enabled`; old solver stays through 2026.
9. Lint: `TableOperations` warns on `#t` or `ipairs` over a table type with no numeric indexer; `MisleadingAndOr` warns only on a literal `nil`/`false` middle operand. Use `if a then b else c` whenever `b` can be falsy.
10. A newer tween on the same property cancels the earlier one (Tween reference page). Different properties can run together.
11. Server memory: formula `6.25 GiB + 100 MiB × largest connected player count`; keep usage below 50%; the 3 GB figure is a secondary guideline from the analytics page because the chart does not show total memory. Server heartbeat is capped at 60. Client target 60 FPS = 16.67 ms; client CPU time below 16 ms.
12. Release facts with dates: Server Authority full release 2026-07-09 (Next Generation Replication is a prerequisite; check its status); IAS full release 2026-06-11 (converted player scripts opt-in via `PlayerScriptsUseInputActionSystem`; default flips ETA early 2027); Animation Graphs full release 2026-07-15 (state machines and Luau expressions still Studio Beta); Scene Analysis out of beta 2026-07-10; `if local`/`if const` Studio Beta since 2026-10-06; Luau 0.743 is 2026-10-16; Lune 0.11.0 2026-10-11; Rojo 7.7.1 2026-10-02; run-in-roblox 0.3.0 2020-07-20.
13. `CollisionFidelity` has five values (Default, Hull, Box, PreciseConvexDecomposition, Tunable); Tunable adds `CollisionPrecision` 0-1; neither is readable or writable by game scripts at run time.
14. Server Authority: write predicted-instance attributes only inside `RunService:BindToSimulation()` callbacks; the first 64 attributes replicate; the visualizer (Ctrl/Cmd+Shift+F6) shows prediction and input-accept rates.
15. `UnreliableRemoteEvent` drops payloads over 1,000 bytes; RemoteEvent order holds across different RemoteEvents per connection and direction, and applies to handler start; Open Cloud Luau Execution tasks run at most 5 minutes with 10 incomplete tasks per place.
16. Teleport does not work in a Studio playtest; test in a published experience.
17. Studio multi-client: up to eight clients; `StudioTestService` runs programmatic multi-client tests.
18. Claude Code facts: Code Review never approves or blocks and "no findings" is not proof; Stop hooks end the turn after eight consecutive continuations; agent teams are experimental and off by default.
