How I checked. Mirror = `knowledge/external/roblox-creator-docs/`, revision 7400643, refreshed 2026-10-20 (`README.md:6-7`). I read the pages named below on 2026-10-21. Paths are relative to the mirror root. `ref/` = `_api-reference/classes/`, `enums/` = `_api-reference/enums/`. Verdicts: confirmed (source matches), corrected (source gives another value), partly (matches with a limit or a missing piece), unverified (not found; I say where I looked), contradicted (source says the opposite).

## Facts the craft book can rely on

Each bullet names its row. "Mirror" claims are from docs dated 2026-10-20; forum claims carry their date.

- Load animations with `Animator:LoadAnimation`; the Humanoid and AnimationController versions are deprecated. (RA05)
- The Animator must be in Workspace before LoadAnimation. LoadAnimation makes a new track every time; keep tracks or fetch with `GetTrackByAnimationId`. (RA03, RA04)
- Replication: NPC and prop animation must be loaded and started on the server; an Animator created on a client never replicates; a player's own client may start tracks on its Character's Animator. (RA02)
- A client-side Animator is the documented choice for large crowds of cosmetic NPCs. (RA02, RA42)
- Priority order high to low: Action4, Action3, Action2, Action, Movement, Idle, Core; resolved per joint; compare by name, never by enum number. Default and catalog clips play at Core. (RA09, RA10)
- Use priority first, weights second: the docs say blending by weight is usually unnecessary where priority fits. Same-priority tracks blend by weight. (RA13, RA09)
- Defaults: fadeTime 0.1 s for Play, AdjustWeight and Stop; weight 1; speed 1. (RA12, RA13, RA14)
- After `Stop()`, call `Play()` before adjusting that track again. Use `Ended`, not `Stopped`, to know influence is gone. Avoid `Stop(0)` on Motor6Ds with MaxVelocity 0. (RA14, RA15)
- Speed: negative plays backward, 0 pauses; real duration is Length / Speed. TimePosition can be set only while the track plays. Length is 0 until the clip has loaded. (RA16, RA17)
- Looping clips do not blend last to first: duplicate the first pose as the final key. (RA18)
- Markers: author them on the Animation Events bar, read them with `GetMarkerReachedSignal(name)`, connect before `Play()`, use the Parameter string for payload. `KeyframeReached` is deprecated. (RA19, RA20)
- The method `GetKeyframeMarkerReached` named in `KeyframeMarker.yaml` does not exist. (RA21)
- Marker behaviour under throttling or low frame rate is undocumented. Use markers for cosmetics only. (RA22)
- `Animator.EvaluationThrottled` is true when the pose was reused; skip procedural offsets then. The reference and an April 2026 post disagree on whether `PreferLodEnabled=false` forces full fidelity; test on a device. (RA24, RA25)
- A cap on playing tracks per character exists and logs a warning; 64 is the 2026 forum-reported value, undocumented. (RA27)
- R15 avatar joints are AnimationConstraints when AvatarJointUpgrade is on; layer procedural motion into `Transform` during PreSimulation. Motor6D remains for mechanical rigs. Never write RigAttachment.CFrame. (RA28, RA29, RA30)
- IKControl: needs Type, EndEffector, Target, ChainRoot; turn it off with `Enabled=false`, not weight 0. (RA33)
- KeyframeSequence is what the editor saves; CurveAnimation is required for emotes and animation packs; converting to curves cannot be undone for quaternions. (RA32)
- CurveAnimation matches joints by folder name and allows partial hierarchies; it can carry FaceControls curves. (RA31)
- Importing animation: Animation Editor, Import, From File (standard R15 rig, exact R15 joint names); the Clip Editor importer handles several clips per FBX or glTF (GA 2026-03-31, forum) and saves locally; upload is a separate step; Import 3D can upload directly. (RA40)
- Avatar animations animate in place; mute root translation before export. (RA41)
- Overrides: set Animate-script AnimationIds from a server Script, or use Avatar Settings Animation Packs and Custom Clips. A replacement default clip needs its last keyframe named `End`. (RA39, RA37)
- Animation Graphs: publish the graph, load it as an animation, drive it with `SetParameter`; state machines and expressions are beta (RR43). (RA38)
- Release scripts and rigs with saved animation metadata removed; release references and connections so animation memory can unload. (RA42, RA43)
