**Recommendation.** Call it "ChatGPT's image model, run through Codex (model version not exposed)" in the skill and the tool's docs. Drop the hard-coded `gpt-image-2` from `reference-images/SKILL.md:42` and from the prompt-patterns header, or say "gpt-image-2 or newer, as of 2026-10-21". Add a model/surface field to each image's `.json` record, filled as "unknown" unless the generation surface shows a name; AN1 in note 03 asks for the same. Treat the 2026-09-08 behavior change risk (CM5, regression set) as real: a model may change under the tool without notice, so keep the comparison set. If the owner wants a named model, the owner can run the ChatGPT app or the API with `gpt-image-2.5-sunburst` or `gpt-image-2.5-flare` and record it.
