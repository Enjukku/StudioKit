## Title/icon testing answer

Does Roblox offer a native test or experiment for titles or icons today (2026-10-21)? None found.

What exists, with sources:

- Thumbnails: thumbnail personalization is the only built-in creative test, and it is an adaptive bandit, not a fixed A/B test (FD-35, FD-36). It covers the Home page thumbnail only, and it needs 2-5 active images (FD-26). Its Open Cloud API is Experimental (FD-71).
- Creator Hub Experiments: in-game config values and matchmaking only (`production/experiments.md:11, 22-25`, FD-73). The Open Cloud Experiments API is the same product and labelled Experimental (FD-70). Neither lists titles, icons or thumbnails.
- Roadmap: the Creator Roadmap Spring Update (2026-05-08, devforum extract) lists Experimentation (A/B testing) as shipped and does not mention title, icon or discovery-metadata testing.
- Creator requests: "Add A/B Testing and Stats for Titles & Icons" (2026-08-06) and "A/B Testing Experience Titles Together With Thumbnails" (2026-09-27) are open feature requests with no Roblox staff reply in the extracts. A third thread, "Icon A/B testing", answered HTTP 410 Gone and was not read.
- A 2024 thread and a third-party guide (found by search, not read) say the same: icons can only be tested one after another. I do not use them as evidence.

Searched: the local mirror (`production/experiments.md`, `cloud/guides/experiments.md`, thumbnails, icons, publish-games-and-places, discovery, discovery-faq), the live thumbnails, discovery-faq and Open Cloud API listing pages, the Creator Roadmap Spring 2026 post, the Weekly Recap 2026-08-28, and DevForum feature-request threads (via WebSearch and WebFetch). Not searched: the Creator Hub UI itself, and any DevForum post after 2026-10-16. So the skill should say "no native title or icon test is documented as of 2026-10-21; verify in Creator Hub before telling the owner none exists", and treat any title or icon change as an observational before/after comparison (also see the 2026-10-12 recording break, FD-51).

## Thumbnail tile size answer

Does any Roblox doc state the display size of a Home thumbnail tile on phones? None found.

What the docs do state, with lines:

- Upload target: 16:9, ideally 1920×1080 (`production/publishing/thumbnails.md:54, 220`); keep personalization uploads under 3 MB and 1920×1080 (:150).
- Display: "Displayed thumbnails will be stretched to 16:9 aspect ratio regardless of the upload's aspect ratio" (:220).
- Overlap: metadata such as the player count may cover the bottom of the thumbnail (:215).
- Icons (not thumbnails): "In some places on the Roblox site and app, icons scale down to smaller sizes like 150×150 pixels" (`experience-icons.md:34`).

Searched: the thumbnails, icons, discovery, discovery-faq and publish-games-and-places pages in the mirror (grep for thumbnail, tile, phone, mobile, pixels across the whole mirror), the live thumbnails page (extract: no tile or phone size), and a web search for DevForum or docs text on phone tiles (nothing official; only low-quality SEO sites, which I did not use). Any pixel size for a phone tile would be the studio's own measurement from a device screenshot, labelled as such.
