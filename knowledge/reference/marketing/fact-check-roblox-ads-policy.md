# Fact check: Roblox ads, money and policy claims (marketing paper, notes 01-03)

## How I checked

- **Sources, in order.** (1) Local docs mirror `knowledge/external/roblox-creator-docs/` (written `MIR:` below, path relative to it). (2) Kit rules `.agents/skills/platform-policy/references/rules.md` (written `RULES:line`, read 2026-10-20 by the kit). (3) Live pages, all read 2026-10-21. A claim is never confirmed from memory.
- **Live reads are model extracts.** WebFetch returns a small model's extract, not raw text. Where an extract is the only evidence I write "extract only". The mirror lines are raw text.
- **Help-center pages.** `en.help.roblox.com/hc/...` HTML answered HTTP 403 (P12, P15, P16). The same articles are readable through the help center's public JSON endpoint `en.help.roblox.com/api/v2/help_center/en-us/articles/<id>.json`. Those reads give `updated_at`: P12 2026-10-12 (page says "Last Updated Oct 9, 2026"), P15 2026-10-08, P16 2026-10-19. All three are extract only.
- **DevForum** threads read as page or `.json` (extract only): P02, P03, P04, P05, P10, P11, S18, and the Ads API test thread. I also read thread replies for P03, P04, P05, P11 to see whether staff changed the post. No reply I could read changes a verdict below.
- **Labels.** Platform rule or limit = RULE. Reported result = EXPERIENCE. Paper advice = OPINION. Moving numbers carry value + unit + URL + date read.
- **Scope split.** Measurement rows (note 03 D16-D20) and non-Roblox rows (YouTube, TikTok, Meta, FTC, Steam, Nintendo) are not mine and are not covered. Note 01 FC-36 (P06-P09 disclosure sources) is non-Roblox, so I left it out.
- **Row id key.** Note ids are written `02 FC-n`, `03 FC-n`, `01 FC-n`, `02 AD-n`, `03 PO-n`, `X-n` with the note number first.

**Corrections, in one list**

1. FA-07: P03 (2026-05-07) gives no attribution window lengths and calls the segments New / Returning / Resurrected. The window table is on the Ads Manager docs page and uses "Recent Users". Do not say the table "matches P03".
2. FA-10: the docs page says up to 10 thumbnails; the newer P03 staff post (2026-05-07) says 25. The two disagree. Do not hard-code either.
3. FA-15: Earnings was announced 2026-05-07 as rolling out "over the coming weeks" to eligible games only. Docs label it "(Limited)".
4. FA-16: Engagement is beta (P04 title and body, 2026-06-16, last edited 2026-07-16). "Launched" is true only as "beta launched". The docs page shows no beta label.
5. FA-23: "No minimum spend" is true of the Ads Manager docs page only. The Open Cloud Ads API requires a budget that "must meet the minimum" (value only in the error message), and the new featured tile (Managed Beta) needs a $5K USD campaign.
6. FA-32: the under-13 restricted-category list in P11 (food, cosmetics, pharmaceuticals, financial services) is older and shorter than P12 (updated 2026-10-09). Use P12.
7. FA-43: docs say submit "at least 5 days" ahead; P11's FAQ says "5 business days". The docs sentence is a recommendation, not a rule.

**Dropped:** FA-26, the "285 Robux" rule: found in no source.
**Unverified:** FA-12 (whether engagement-based creative optimization ever went live), FA-22 (Sponsored Tile video live today), FA-24 (a maximum account spend).
