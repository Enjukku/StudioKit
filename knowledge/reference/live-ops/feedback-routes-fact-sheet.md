# Feedback routes: what Roblox and Discord allow today (fact sheet, J014-T03)

Scope: facts only, per question Q1-Q8. No route is recommended and no setup steps are written. The lead designs the plan from this sheet.

## How I read, and what the verdicts mean

- Read date for every row is 2026-10-21. "Mirror" = `knowledge/external/roblox-creator-docs/` at upstream revision `7400643` (refreshed 2026-10-20); the mirror holds no page-level dates, so the source-date cell says "mirror 2026-10-20". Paths below are relative to that folder unless they start with `.agents/`.
- WebFetch returns a model extract of a page, not the raw page. Every "source says" cell that comes from a web page is therefore the extract's text. Quotes are 15 words or fewer; longer clauses are paraphrased and marked.
- Web search results were used only to find URLs. No row rests on a search summary alone. Rows that rest on a search snippet are marked `third-party` and listed in "Not read" at the end.
- Verdicts: **DOC** = Roblox or Discord official documentation page. **POST** = Roblox staff DevForum post (staff status as shown in the topic data). **TERMS** = terms, policy or community-standards text. **third-party** = anyone else (community post, vendor, blog, news). **not found** = searched, nothing usable (the row says what was searched).
