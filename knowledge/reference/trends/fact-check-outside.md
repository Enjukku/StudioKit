## 1. Method and limits of this check

- Primary pages were read with the web fetch tool, which summarises the page. Every clause I rely on for a ruling was then read again in the raw page text (curl, one read per page, honest user agent) or is marked "summary only". Pages that need JavaScript (TikTok For Business terms, Instagram Terms of Use, TikTok Creative Center live pages, Apple builder dropdown values) could not be read; they are marked blocked or unverified.
- Quotes are under 15 words. A quote from a summary-only read is marked "(summary)".
- Extra requests beyond one per page, for honesty: the Apple builder page returned 504 once (no fixture kept) and I made one extra HEAD request to it; `ads.tiktok.com/robots.txt` was read twice (once to read, once to save the raw fixture). No loops, no polling, no login, no key, no cookie.
- Pages that embed Google public API keys (developers.google.com) were kept only in the session scratchpad, never in the repo.

## 4. What a person may read and record by hand

Rule for all rows: read the public page as any visitor would, without a login that bypasses a gate, without browser automation, without scripts. Record facts (names, ranks, counts as shown, dates), the country or region, the time window, the page URL and the read date. Record no personal data of private people, no children's profiles, no copied media, no screenshots of other people's content. Store short notes, not page copies. The 30-day and 24-hour storage limits above bind developers using the API; they do not apply to a person's own notes from a website, but the notes should still be short, dated and aggregate.

| source | read by hand | record |
| --- | --- | --- |
| Steam store charts | Top Sellers, Most Played, weekly Top Sellers on the public charts page | rank, app name, app ID, country or global, date and time, free-to-play flag |
| SteamDB | public chart pages, viewing only | app ID, peak shown, date; never export in bulk |
| Google Play | public Top charts per country and category | rank, app name, category, country, date |
| TikTok Creative Center | public Trends hashtag pages and Top Ads | country, time window, hashtag name, rank, figures as shown, first seen and last seen, advertiser name and mechanic for Top Ads |
| Instagram | public pages without logging in on the scout's behalf | hashtag or sound name, figures as shown, date |
| Google Trends | explore page in a browser, download button | terms, geography, category, interval, the 0-100 values, date; keep the comparison set identical |
| Twitch | public directory pages | top categories and the viewer counts shown, date and time |
| YouTube website | public search and channel pages | video ID, title, channel, views as shown, date (own notes, not API data) |
| Reddit, Discord | public pages or servers where the person is a normal member | topic, date, link; no usernames or message copies; follow each server's rules |
| Release calendars | official news pages | title, date type (announced, released), URL |
