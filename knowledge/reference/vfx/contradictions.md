# VFX reference: contradictions register

**Scope and use.** One table of every unresolved or contextual disagreement found across the two research runs (Claude 2026-10-12 files, ChatGPT independent package incl. `contradictions.json` AUD-01..AUD-10) and across the section files 01-07, plus the PROPOSAL values that two section files set differently. The VFX agent reads the "status" cell before it uses a contested number: it says which reading wins and why, or "unresolved" (then use both with their tiers, or run the named test).
Rows X-01.. are evidence or reading disagreements. Rows PD-01.. are PROPOSAL divergences between section files: none is evidence; the status cell names the start value to use until the owner confirms or a test (`12-gaps.md`) replaces it. Sources are R-ids from `00-sources.md`. "Integration fixes" lists every edit made to the section files during integration (2026-10-13).
