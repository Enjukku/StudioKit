# VFX reference 02b: moment recipes for rewards, reveals, movement, mood and UI

Scope and use: Output 2 part B (moment recipe table) for collecting and rewards, egg/chest reveals by rarity, movement, ambient mood and UI moments in a mobile-first Roblox brick game; hits, blasts and destruction are part A. Merged at claim level from the Claude research (gap files win over first-run files) and the ChatGPT independent package; sources are cited only as R-ids from `00-sources.md`.
Evidence for this family is thin: almost every duration and every importance rating is a `PROPOSAL (inference)` with a basis and a test id (T#, section "Open / test ourselves"). Design numbers stay proposals until the owner confirms. Proposals marked "same as 05 P-xx" reuse the starting values in `05-juice-repetition-sync.md`; flipbook mechanics are in `04-field-methods-flipbooks.md`.

## Keys

| key | meaning |
| --- | --- |
| evidence level | study / preprint / industry practice (person or studio, year) / spec / inference. Tier D is a lead, never proof. "single tier C" = only one tier-C publication supports it. Two runs reading one publication = one source |
| PROPOSAL | `PROPOSAL (inference): value; basis: ...; tune by: T#`. Never an evidenced number |
| phases | W windup, P punch, C crescendo, F follow-through, D dissipation (field terms: R-345, R-346 VFX Apprentice 2025, tier C; dissipation also in R-310; the five-phase split is a working vocabulary, not a standard). "hold" = item or state stays still and readable. Times in ms; P = 0 unless stated |
| "ChatGPT recipe" | the ChatGPT package's own recipe row for the same moment (`02_moment_recipe_table.json`): labelled inference by its authors, no source behind it; used as a second model's design reading, not as evidence |
| trigger | P fires on the server-confirmed state change (credit, sale, purchase, roll result), never on the request (G1) |
| frames | Roblox targets 60 FPS = 16.67 ms per frame for the whole frame, not for VFX (R-217, spec). Source frames are converted to ms only where the source states fps |
| importance rating | Riot designers rate each effect 1-10 separately for caster, allies and enemies (R-368, Beardilocks 2020, single tier C; the ChatGPT ledger cites the same post). No source in either run maps the rating to size, brightness, duration or layer count. Ratings below are PROPOSAL "self / other player" on that scale. Combat danger from part A always outranks reward and mood: gameplay information first, theme last (R-060 Riot 2022, R-080 Riot 2021, industry practice) |
| viewer split | Other players' reward and movement VFX are reduced; own effects and threats stay full. Shipped structure: WoW 11.2 Spell Density reduces only other party or raid members' visuals; own, pet, NPC and enemy-player visuals stay full (R-028, Blizzard 2025, relayed in a forum thread); Marvel Rivals lets a player hide Team-Up VFX on their own screen (R-008, NetEase 2026); industry practice, no % published |

| id | rule | evidence |
