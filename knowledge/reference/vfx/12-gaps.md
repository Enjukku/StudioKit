# VFX reference 12: gaps (Output 12)

**Scope and use.** Every question the two research runs do not answer, collected from the "Open / test ourselves" sections of 01-07 and 10-11, the Claude gap-run "Still open" tables, ChatGPT `12_gaps.json` and `contradictions.md`. Each row says why the gap matters to the VFX agent, the best current anchor (R-id, or "no number found") and a test we can run ourselves in Roblox.
Missing evidence is a result, not permission to invent a default: until a row's test has run and the owner has confirmed the result, the agent uses the PROPOSAL start value named in the section file or in `contradictions.md` (PD rows), and labels results "owner-measured".

Keys:
- Sample codes: **S-own** = owner judges on his phone and a PC; **S-5** = owner + at least 5 testers, at least 20 trials per level per tester; **S-cap** = automated Studio or device capture, 3 runs per condition, fixed seed; **S-dev** = device matrix: baseline 2 GB-class Android at 30 fps, a mid phone at 60 fps, a PC; quality level 1 and 10; **S-src** = source retrieval (owner opens a link or supplies a PDF), then the agent re-reads it.
- Pass rules marked (P) are PROPOSAL (inference) test criteria; the owner may change them. Device and setting of every measurement are recorded (03 V-41).
- "from" = where the gap was raised: section test ids (01 table rows, 02a T-*, 02b T*, 03 V-*, 04, 05, 06 T-*, 07 O-*), ChatGPT `12_gaps` names (GPT: ...), Claude gap files (gap-*).
