# VFX reference 02a: moment recipes, action moments

**Scope and use.** One row per action moment (hits, explosions, breaking, abilities and weapons, warnings) for the future VFX-designer agent that kitbashes flipbooks and Roblox parts. Material rows apply to a brick's material tag; "toy plastic and bricks" is the default brick.
Cells cite the shared evidence blocks (E-*) below instead of repeating numbers. Every number carries an R-id from `00-sources.md` and an evidence tag. PROPOSAL values are starting points, never evidence (owner rule: design numbers are proposals until the owner confirms); each names a test (T-*) in "Open / test ourselves".
Merged from the Claude research files (verifier corrections applied, gap files over first-run files) and the ChatGPT package (02_moment_recipe_table, supporting_reference, claim_ledger). The ChatGPT table gives no numbers for any action moment; its rows are inferred recipes, kept here as qualitative rules tagged [inf].

## Legend

| key | meaning |
| --- | --- |
| [st] | study (peer-reviewed or conference paper) |
| [pp] | preprint |
| [ip: maker year] | industry practice, named maker or studio and year |
| [sp] | spec (engine or standards docs) |
| [inf] | inference (our reasoning, or arithmetic on a cited value) |
| [lead D] | tier D source: a lead, never proof, never the only support for a rule |
| single C | only one tier C publication supports the claim |
| f (fps n/s) | frame count as written by the source; the source states no fps, so no ms conversion (merge rule 6) |
| f@60 | our frame unit for PROPOSALs: 1 f@60 = 16.7 ms; Roblox's documented default target is 60 FPS, 16.67 ms per frame (R-217 [sp]) |
| W · C · P · F · D · HS | windup · crescendo · punch · follow-through · dissipation · hit-stop |
| PROPOSAL (inference): v; basis: b; tune by: T | a starting value with no direct evidence, its reasoning, and the test that replaces it |

## Build notes for a flipbook agent

### Roblox facts used below (local docs mirror, spec)

- Flipbook sheet: playback requires a 1024×1024 texture; otherwise the engine sets NotCompatible and turns flipbook playback off (R-214). Layouts 2×2 = 4, 4×4 = 16, 8×8 = 64 cells, or Custom via FlipbookSizeX/Y (R-209, R-211). Cell size: 1024/8 = 128 px, 1024/4 = 256 px [inf arithmetic]. Leave transparent spacing between cells (R-209). See Conflicts C-10.
- OneShot ignores FlipbookFramerate: time per cell = Lifetime / cells (R-209). Example: 16 cells over 0.5 s = 31 ms per cell, about 2 f@60 [inf arithmetic]. Loop, PingPong and Random use FlipbookFramerate, max 30 fps (R-209).
- FlipbookStartRandom + FlipbookFramerate 0 = every particle is one random static cell (R-209): chips, shards, splinters. Never random-start a meaningful one-shot (flash, telegraph) [inf].
- Low-memory clients switch flipbooks off, likely on older phones (R-209): every primary layer needs a readable non-flipbook fallback (static texture or mesh) [inf].
- Rate ≤400/s per emitter (100/s on mobile); Lifetime ≤20 s (R-209). Caps, not budgets.
- LightEmission 0 = normal blend, 1 = additive; with LightEmission >0 darker colours render more transparent; it does not light the world (R-211, R-202). LightInfluence 0 = self-lit, 1 = lit by the scene (R-211).
- Orientation: VelocityParallel (streaks), VelocityPerpendicular, FacingCameraWorldUp (R-215). Squash >0 narrower and taller, <0 wider and shorter (R-211). ShapeInOut Inward emits toward the shape centre (R-211). ZOffset changes render depth only (R-211). TimeScale 0-1 (R-211). Emit(n) bursts (R-211).
- PointLight Range is clamped to 120 studs (R-203).
- Highlight: 255 simultaneous slots, disabled ones still use a slot (R-195); DepthMode AlwaysOnTop shows through walls, Occluded hides behind them (R-195).
- ColorCorrectionEffect: Brightness −1 (black) to +1, Contrast, Saturation (−1 = grey), TintColor (R-184); parented to the Camera it shows to that player only (R-219); post effects can change at low quality and do not affect GUI (R-220).
- Camera FieldOfView is clamped 1-120°, default 70 (R-182). Shake = a per-frame CFrame offset applied after the camera script [inf]; RbxCameraShaker is one Roblox implementation (R-403).
- Hit-stop: AnimationTrack:AdjustSpeed(0) pauses an animation (R-171); ParticleEmitter.TimeScale 0 freezes particles (R-211); the mirror documents no global time scale, so physics keeps running [inf].
- Beam: Segments ≥ n−1 for n colour/transparency keypoints, default 10; TextureSpeed in cycles per second (R-177). Trail: Lifetime 0.01-20 s, default 2; Clear() empties history (R-236).
- Placement: the server sends the break or hit event; cosmetic chips, dust and VFX are client side (project rule: server authority, AGENTS.md §2; per-client culling of debris, R-021).
