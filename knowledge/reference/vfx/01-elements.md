# VFX reference 01: element table (Part 1)

**Scope and use.** What each controllable element (gameplay, shape, value, colour, timing, composition, camera) does to feeling and energy, merged at claim level from the Claude research files (first run + gap run, verifier corrections applied) and the ChatGPT independent package. Every number carries a unified source id from `00-sources.md`; corroboration counts distinct publications, not models.
Use: find the element, take the evidenced number or the labelled PROPOSAL as a starting value, then run its "tune by" test. Moment recipes, scene rules, Roblox limits and mistakes are Outputs 2-7; this file names only the Roblox facts an element needs.

Keys:
- `[R-xxx T]` after a number = source id and register tier (A, A-, B, B-, C, C+, C-, D, spec). Tier D = lead only, never proof.
- Evidence level: study / preprint / industry practice (who, year) / spec / inference. `single C` = rests on one tier-C publication. `corr N` = N distinct publications agree. `pre-2020` marked in the source column.
- `fps n.s.` = source gives frames without a frame rate, so no ms conversion (merge rule 6).
- `PROPOSAL (inference): value; basis; tune by` = our starting value, not evidence. Design numbers stay proposals until the owner confirms (AGENTS.md §0).
- R-120 (Riot 2017 LoL VFX style guide) was read in full only by the ChatGPT run, from an unofficial community mirror; the Claude run saw it second-hand through R-360 (VFX Apprentice).
