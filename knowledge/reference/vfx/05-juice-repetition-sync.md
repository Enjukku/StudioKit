# VFX reference 05: juice and satisfaction (Part 5), repetition (Part 6), effect and sound sync (Part 7)

Scope and use: Output 5 table plus Parts 6 and 7, merged at claim level from both research runs (Claude: p5-p6-p7, gap-juice-studies, gap-repetition-escalation, p1-composition, gap-hitstop-shake-flash, gap-rewards-reveals; ChatGPT: 05 table, supporting_reference, contradictions, claim_ledger). The VFX agent uses it to decide what a hit, brick break, pickup, coin, reward or UI cue needs to feel good, how to vary and cap repeats, and when the sound fires.
Every number carries an R-id (`00-sources.md`) and an evidence level. `PROPOSAL (inference)` values (section "Starting values") are starting points, not evidence; design numbers stay proposals until the owner confirms. Frames become ms only where the source states its fps.

Keys:
- Evidence level: study | preprint | industry practice (who, year) | spec | inference. "abs" = only the abstract or a project page was read: direction only, no method detail.
- "1 pub, both runs" = the same publication read by both runs: one source, not two. Corroboration counts distinct publications.
- "single tier C" = the claim rests on one tier C source. Tier D is a lead, never proof.
- Effect-size scales: b = unstandardised path coefficient (scale points of 7-point questionnaires, playtime paths in minutes per scale point); η²p = partial eta squared; η² = eta squared; W = Kendall's W; d = Cohen's d; d' = sensitivity index; EMM = estimated marginal mean.
- Juice definition used by the studies: excessive amounts of feedback in relation to the user input (Juul's definition, quoted in R-043).

### 5c. What satisfying effects share

| quality or finding | why it works (or fails) | how to make it | game uses | effect size if known | evidence level |
| --- | --- | --- | --- | --- | --- |
| Outcome-bound: the effect shows that the player's action caused a result | Competence and effectance need the action-outcome link; amplification that hides it lowers them | Contact first, then consequence, in one readable order; the payoff sits on the result | All moments | see 5a rows 1-2 (R-043) | study (R-043) + industry practice (R-110) + preprint (R-073); 3 distinct pubs |
| Graded by real importance (hierarchy) | A basic hit as big as the top tier confuses viewers and devalues the top tier | Size, brightness, duration and screen area grow with importance. Riot rates each spell's importance 1-10 separately for player, allies and enemies (reported); no source maps the rating to size, brightness or duration | Every effect class; tier table per game | no number found for the mapping | industry practice: Riot 2017 guide (R-120, A, read via unofficial mirror by ChatGPT run), Clarity in League 2021 (R-080, A), Beardilocks 2020 1-10 rating (R-368, C, no second source for the scale), VFX Apprentice summary (R-360, C); 4 distinct pubs for hierarchy, 1 for the 1-10 scale |
| Several channels hit the same event | Hit-stop, sound coherence and camera control co-occur in the best-rated games; multimodal is a core juice trait | Shape + flash + sound on one event, haptic and shake by tier | Hits, breaks, eggs | see 5b | preprint (R-073) + industry practice (R-110) + study (R-044 qualitative, R-086 abs) |
| Timing shape: windup, punch, follow-through, dissipation | Anticipation, then payoff at the expected moment, then room to process; reward feedback works best after the action | Windup before the hit; punch on contact; follow-through carries mass and reward; short dissipation on frequent effects | Charged shots, C4 fuse, eggs, sells | R-005 Study 2 (post-action gain, numbers in 5a) | industry practice (R-120 A 2017; R-360 C) + preprint (R-005) + study (R-020 abs) |
| Contrast and restraint | Peaks need a quieter baseline; extreme builds lost to medium; experts reserve standout moments | Frequent effects small and short; spend brightness, shake and length on rare events | Whole-game tuning | R-101 (5a); no threshold number | study (R-101, R-044 qualitative) + industry practice (Eiserloh 2016 R-124; Riot 2017 R-120 demotes outros) |
| Immediacy | A response within 0.1 s reads as instant | First visible and audible response on the input or confirmation frame | Taps, pickups, buttons | 0.1 s instant, 1 s flow, 10 s attention (R-153, 1993); UI feedback 100 ms (R-370) | industry practice (Nielsen 1993 R-153, pre-2020; NN/g 2020 R-370 C) |
| Smooth motion curves | Developers describe good feel as smooth curves and immediate reaction; linear timing everywhere hides acceleration and release | Eased curves for pops, flights and counters; keep projectiles constant where speed matters | UI pops, coin flights, scale-ups | none | industry practice (R-110) + inference |
| Clean ending (completion, closure) | Plausible goal: an unambiguous end state reads as finished | End each event in a stable readable state (debris settled, counter final, item shown) | Collapse, coin counter, reveal | no study found by either run; no number found | inference |
