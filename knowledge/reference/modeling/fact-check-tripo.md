# Fact check: Tripo claims in the modeling paper (J007-T07)

**How I checked.** Read date for every row is 2026-10-21 (today), from the live page. I read Tripo pages as plain text with a small read-only GET script (page text only, no login, no API call, no account, no credits, no file downloads other than page text kept in a scratch folder). Pages: Tripo developer docs and model cards, the Tripo blog and help pages, the Studio product docs (`tripo3d.ai/product-doc/...`, each dated 'October 2026'), the Terms, the vendor pricing pages, two third-party reviews and four arXiv papers (abstract and HTML versions). The Studio sidebar links were not in the HTML, so I found the product-doc pages by guessing their paths from the sidebar titles. Studio is a login-only app and I did not open it. So every Studio finding means 'the vendor docs say Studio has this control'. It does not mean I saw the control in the live UI. Tripo help and API pages carry no date; only model ids, the changelog headings (month only), the product docs ('October 2026'), blog index dates and arXiv dates are dated. Vendor pages prove what Tripo offers, never output quality. Rows marked 'reused' come from `knowledge/reference/rigging/fact-check-tools.md` (RT ids); I did not re-check them, but the page was in front of me and I note when it had changed (it had not). The Digital Production and GLBGPT reviews are experience with a sample size of one article each. The GLBGPT page is Dutch and I read it in Dutch. Quotes are under 15 words.

Verdict words: confirmed, corrected, partly, unverified, contradicted, reused. Surface: API = Tripo developer API, Studio = Tripo Studio web app and its product docs, both, unknown. Every checked-against cell prints the full URL and the read date.

## Summary

Claim rows: 58 (MT01 to MT58). Verdicts: confirmed 49, reused 7, partly 2, corrected 0, contradicted 0, unverified 0.
Extra rows for facts the paper did not state: 12 (MT59 to MT70). Verdicts: confirmed 11, unverified 1.

What changed or needs care:

- No paper claim was corrected. Two are partly: the 2026-10-10 date of the September update could not be reproduced (MT06, MT54), and the P2.0 Official page (T06) shows index date 2026/08/19 with text edited later.
- The paper's API facts are right, but most differ in Studio. Studio P Series makes geometry only, Studio Retopo allows 500-50,000, Studio Smart UV discards textures, Studio Remove Lighting defaults Off. See the Studio table and MT61 to MT68.
- The paper never says that H3.1 has an API low-poly mode (smart_low_poly, 500-20,000 faces). It fits the 7,000-triangle budget, but no Studio control for it is documented (MT59, ST08).
- Licence sources still conflict (MT46, MT47, MT48). Left open on purpose.
