## Rules a skill may state

Paths are relative to the mirror unless a URL is given. Wording is mine. All limits read 2026-10-21.

1. Generic mesh: at most 20,000 triangles; watertight, quads where possible, real thickness. Not a phone budget. (MR01; `art/modeling/specifications.md:34-37`)
2. Name the asset category first: generic mesh, avatar body, rigid accessory and layered accessory have different limits. (MR02; `art/modeling/specifications.md:13-34`)
3. Avatar body (Marketplace): head 4000, torso 1750, each limb asset 1248, total 10,742 triangles. (MR03; `avatar/character-bodies/specifications.md:381-431`)
4. Marketplace accessories (rigid or layered): single mesh, at most 4k triangles. Marketplace textures at most 2048x2048. (MR04, MR05; `avatar/layered-accessories/specifications.md:29-30, 63`; `avatar/rigid-accessories/specifications.md:25-26, 341`)
5. A vertex has at most 4 bone influences; none on Root; Root at 0,0,0; bones frozen (scale 1, rotation 0). (MR06; `art/modeling/specifications.md:56-60`)
6. One material per mesh; one UV set per component, UVs inside 0-1; overlapping UVs allowed. (MR12; `art/modeling/texture-specifications.md:30, 128-130`)
7. The engine renders textures up to 4096x4096; 8K can be uploaded and is kept at original quality but runs at 4K at most. Roblox's size guidance: 256 for 5x5 studs, 512 for 10x10, 1024 for 20x20; for PBR maps 256 per 2x2x2 unit space with 1024 as the stated maximum. The page contradicts itself, so state "4K supported, not a target". (MR08, MR09, MR11; `art/modeling/texture-specifications.md:23-27, 84-131`; DevForum 4k-texture-rendering, 2026-01-30)
8. 4K is not guaranteed on every phone: texture streaming disables 4K on low-end Android under 3.5 GB (update 2026-03-23). UI, SurfaceGui, Terrain, TerrainDetail and Sky textures were not yet supported at that date. (MR10; DevForum introducing-texture-streaming, 2025-12-12, update 3/23/26)
9. Normal maps: OpenGL tangent space only; export tangents; flip G if bumps look like dents. (MR19; `_api-reference/classes/SurfaceAppearance.yaml:300-330`)
10. SurfaceAppearance has five map types (color, normal, roughness, metalness, emissive mask); emissive reads only the red channel of an RGB mask; Marketplace emissive strength 0-40 (bodies, heads, layered clothing, MeshPart accessories). (MR17, MR18; `art/modeling/surface-appearance.md:53, 461-468`)
11. Batching: meshes with the same MeshContent share a draw call only when SurfaceAppearances match (or TextureContents, or materials). Upload each mesh once and duplicate in Studio; the importer does not de-duplicate. (MR24; `performance-optimization/improve.md:319-329, 398-405, 580`)
12. CollisionFidelity has five options: Default, Hull, Box, PreciseConvexDecomposition, Tunable. Tunable adds a CollisionPrecision slider (0 to 1; set in Studio); Tunable did not replace the others. (MR25; `parts/meshes.md:141-147`; `_api-reference/enums/CollisionFidelity.yaml:19-49`)
13. Mesh streaming (Workspace.MeshStreamingAndImprovedLoDs): when enabled, MeshPart.RenderFidelity is ignored. The opt-in post is dated 2026-04-27; default-on was forecast for about July 2026 and I found no confirmation. Skinned meshes are not supported by it; collision is not changed. (MR26, MR29; DevForum opt-in post 2026-04-27; early-access post 2026-03-16, update 2026-06-17)
14. Legacy RenderFidelity Automatic bands: under 250 studs highest, 250-500 medium, 500 and over lowest; applies when mesh streaming is not enabled. (MR28; `parts/meshes.md:110-137`)
15. 1 stud = 28 cm; 1 RMU = 21.952 kg. For Blender: Unit System None, Apply Scalings = FBX Unit Scale, Add Leaf Bones off, Path Mode Copy with embedded textures, Bake Animation off unless animating; glTF needs no scale setting. (MR35, MR36, MR38; `physics/units.md:39, 44`; `art/blender.md:34-35, 122, 131`; `art/modeling/export-requirements.md:30-46`)
16. Importer defaults: Scale Unit Studs, World Forward Front, World Up Top, Set Pivot to Scene Origin on, Merge Meshes off, Keep Zero Influence Bones off. (MR41, MR42; `studio/importer.md:238-243, 296-301, 319-324`)
17. glTF import nests each mesh node in a Model with one MeshPart per primitive; read the live importer page, section "glTF import hierarchy" (not yet in the mirror). (MR40; RR23)
18. Reimport keeps properties, hierarchy, CollisionFidelity and RenderFidelity, file path, preset and upload inventory; it does not version assets. Rig reimport deletes bones missing from the new file and replaces WrapTargets. Auto-Reimport is a Studio beta. (MR44, MR45, MR46; `art/modeling/reimport.md:35, 104`; DevForum reimport posts 2026-05-06 and 2026-09-08)
19. Asset privacy: since 2026-05-05 new accounts and groups default to Restricted for new images, meshes and decals; Open Use cannot be reversed; an experience's permission cannot be revoked. (MR43; `projects/assets/privacy.md:26-40`; DevForum 2026-05-05)
20. Measure on a phone. 33.33 ms = 30 FPS, 16.67 ms = 60 FPS. Scene Analysis (Window > Performance Summary > Scene Analysis) shows triangles and draw calls by render pass, on the local machine only. (MR32, MR33, MR34; `performance-optimization/scene-analysis.md:17, 78`; `microprofiler/index.md:56-61, 86`)
