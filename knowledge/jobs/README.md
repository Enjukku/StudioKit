M and L jobs get a folder `knowledge/jobs/<job-id>/`, copied from `templates/jobs/`.

| File | From template | Holds |
| --- | --- | --- |
| job-card.md | job-card.md | Size, goal, crew, budget, gates |
| brief.md | intent-brief.md | What and why per craft |
| beat-sheet.md | beat-sheet.md | Shared beat list (cutscenes, effects) |
| ledger.md | ledger.md | Tickets between agents |
| decisions.md | (own table) | Gate answers with the owner's words |
| digest.md | decision-digest.md | Open owner questions |
| `<role>/` | | Each craft's output files |

Job id: `J<nn>` plus a short slug.
