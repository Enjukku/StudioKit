# Lessons: accepted

> Author: kit-writer · claude-sonnet-5-5 · medium · 2026-10-20

Accepted lessons, grouped by area: `knowledge/lessons/<area>/<slug>.md` (areas such as art, animation, vfx, sound, ui, code, process, design).

| Rule | Detail |
| --- | --- |
| Who writes here | Only `/improve` promotes a draft from `knowledge/inbox/` (`.agents/workflows/improve.md` step 3). Nobody else adds files. |
| Promotion test | It happened twice, or the owner stated or confirmed it. |
| Frontmatter | `type: lesson`, `status: active`, `scope: universal` (kit candidate for `/kit-sync`) or `scope: game`. Never mix scopes. See `rules/knowledge.md` §3. |
| Evidence | Every lesson links its evidence: draft, job ledger row, screenshot, log, owner words with date. |
| Replacing | Set the old lesson `status: superseded` and link the new one. |
| Further promotion | A lesson that belongs in a skill, rule or overlay moves there via `/improve` or `/integrate`; leave a link here. |
