When reading an existing game as a case: state the twist as a consequence rule (what decision or outcome it changes), not a theme noun; write the shareable moment as setup → decision → consequence → payoff and name the social consequence; run the title test (C-02) and say when the click rests on a franchise name (a click source the studio cannot borrow, flag as blocking rights question).

**Why:** J003-T08 skills test (2026-10-20) graded readings on these fields; the case-library §4 patterns (consequence-rule twists, social moments) made each reading sharper. Graders also check that no number appears without `not verified`.

**How to apply:** any case reading or competitor teardown. Mark every reading OPINION, mark brief-supplied counts `not verified`, and separate "description says" from "my assumption" (e.g. what gathered resources do). See [[game-concept-pitching]].
