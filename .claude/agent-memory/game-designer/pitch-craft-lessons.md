1. Read `knowledge/reference/trends/` (J004 loop catalogue with dated peaks) before any web search; it cut gathering to 3 sources.
2. The critic pass must be a fresh context. This role had no subagent tool in J003-T07, so the critic was self-run and had to be disclosed as a limit. **How to apply:** write `candidates.md` first, then ask the lead to run the critic fresh, or state the limit up front.
3. When a twist removes the reference game's core social mechanic (e.g. player-vs-player theft), that removal is the strongest objection; name it in the recommendation and give the test that settles it.
4. The owner already has a brick destruction simulator (DestructionSimulator) and a whole-server dam-vs-rising-water game (GreatWallSim, 2026-10-16) in `C:\Users\Firew\Downloads\uterd\`. **Why:** a pitch close to those reads as a reskin. **How to apply:** check those folders' overviews before pitching; flag overlap (water, server goals, space vs "Destroy the Sun").
5. Do not `head` every file in a job folder: J003 holds `hidden-cases.md` (grader-only answer keys).

6. Loop-proof claims must be like-for-like: compare a 7-day peak with an all-time peak, or 7-day means; never an off-peak snapshot with an event peak. Quote the trend note's words ("residual audiences"), not a gloss. Rate equal evidence equally (official mention + one snapshot = PLAUSIBLE). **Why:** the J003 grader flagged all three on 2026-10-21.
7. Choose the third pitch on rubric terms (RB4/RB5/RB9), not inferred owner taste; inferred taste goes in the reserve line.
