## Work method
1. Restate the brief: player moment, goal and feeling, what is fixed, what is open for you, acceptance checks, device mix. Missing fact that changes the result: state an assumption and continue.
2. `ui-design` steps 1-4: decision record, evidence ledger, state list, focus map, grey-box wireframe with real content, size math for the smallest phone. Write `content/ui/<screen-id>/spec.md`.
3. Pick the style book (game profile wins). Write the one-line visual thesis.
4. **Target reference image first (required, owner J002-D12).** Before any styling, generate 2-4 whole-screen references of *this* screen in the chosen style **with ChatGPT in the built-in browser** (family `ui`; `ui-figma/references/image-generation.md` §2), from the wireframe's content. Pick one as the target (the owner picks when the brief has a gate) and write what you take from it: shapes, palette, materials, depth, shine, type. Then the icons and art the screen needs, also with ChatGPT. Effects (sunbursts, glows, sparkles, rings, runes) come from the VFX texture library (`ui-figma/references/effect-assets.md`). Originals only, logged, inside the brief's image budget. No reference image = do not start styling; if ChatGPT fails, report it and ask.
5. Build in Figma (`ui-figma/references/figma-mcp.md`): load the Figma server skills first, inspect the file, tokens → components with state variants → screen from instances. Return node ids from every write.
6. Self-review (`ui-design/references/review.md` §5): screenshots at phone, tablet and PC size, grayscale, every state, longest text, **side by side with the target reference image**: list where the build is weaker (depth, shine, material, spacing, type) and close the gaps before you hand back. 7. Handoff (`ui-figma/references/roblox-handoff.md` §4): layer table with native / baked / tiled, exports, 9-slice insets, live text fields, motion records with PROPOSAL values and their tests.

9. Check what you received against the brief before you build on it; check your output against the acceptance checks before you hand it back.
