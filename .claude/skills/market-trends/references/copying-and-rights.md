# Copying a loop vs copying expression

## 1. The line
| Free to borrow (abstract) | Not free (expression or identity) |
| --- | --- |
| a game idea, rules, method of play, a loop structure: "the idea for a game is not protected by copyright" (U.S. Copyright Office, FR I01) | art, models, textures, UI art, text, rule text, music, sound, video |
| program logic and algorithms in the abstract (FR I02) | another developer's code (the expression in the program) |
| a genre, a family, a mechanic | characters, names, logos, catchphrases, recognisable scenes |
| a human behaviour or tension behind a meme ("a helpful companion turns unreliable") | the meme's character, its name, its song, its copied scenarios |
Names can be outside copyright and still confuse buyers about the source (trademark, USPTO "likelihood of confusion", FR I03). Changing a spelling or adding "inspired by" grants no rights.

## 2. Roblox's own two tests (separate from the law)
1. **IP:** Roblox removes infringing content and "suspends or terminates the accounts" of users who repeatedly or seriously infringe (FR I04). The IP guidelines do not address copying mechanics.
2. **Discovery:** games whose metadata and place files closely resemble existing games "are no longer prioritized for recommendations and might rank lower in search results" (FR D05). A legal copy can still be invisible.

## 3. The gate for every opportunity card
| Check | pass | HOLD | fail |
| --- | --- | --- | --- |
| Code and assets | made by the studio or licensed with documents | licence unclear | taken from another game |
| Title, thumbnail, icon | distinct | resembles a hit | same or confusingly similar name or look |
| Characters, story, franchise | original | a franchise theme without a licence (anime, shows, films, creators' characters, memes) | uses the franchise's characters or names |
| Music and sound | licensed or original (recording, composition, remix and in-game use are 4 separate rights) | source unclear | a trending song used because it trends |
| Gameplay difference | a change visible in the first session | only cosmetic changes | none |
| Platform rules | `platform-policy` checked (paid random items, age, chat, ads) | not yet checked | breaks a rule |
No safe copying percentage exists (N1 §14). When a card says a loop is borrowable, give the basis in one line (U.S. Copyright Office: game ideas and methods of play are not protected; FR I01) and list what clears a HOLD: a licence, or an original identity plus a first-session twist plus independently made assets. One HOLD row → card is HOLD for that branded version; an original design on the same abstract loop may continue. One fail row → that version fails.

## 4. Licensed themes
Roblox's IP licensing tools allow a theme only when a rights holder offers it: check territory, term, revenue share and allowed content. A licensing catalogue is not a blanket licence for any show, anime, creator character or meme (N1 §14).

## 5. People and audiences
- Track creators by exact channel ID, never by a shared display name (two channels can share one).
- Never collect viewers' personal data, never infer individual ages, no children's profiles. Audience is described by cohort ("U.S. players 13-17 per Roblox's own data"), with its source.
- Community dislike of copies can be studied with a disclosed sample of public comments; there is no measured platform penalty for it.
