# Elements: what each acoustic element does

Check the evidence before trusting a number. "lead" = not fetched; never above inference. Nearly all study data are
music or lab stimuli, not game SFX. Arousal = activation; valence = pleasant vs unpleasant.

## B. Element rules

| ID | Rule | Evidence |
| --- | --- | --- |
| S-03 | Tempo is the second dial: up for energy, down for calm; take BPM from genre presets (no slope exists). | study + practice |
| S-04 | Never build a feature that needs the heart to lock to the beat. | study |
| S-05 | Good-vs-bad jingle pair: good one about 2 st higher and 29% faster, then listen-test. | study |
| S-06 | Tense or sad melody: steps <200 cents, m2, m3, tritone, m6; happy: ≥200 cents, M2, M3, M6. | study |
| S-09 | To push valence down add noise or an abrupt pitch drop; arousal rises only if the picture agrees. | study |
| S-10 | "Something is coming" = rising level on a pitched tone; test 20 dB over 750 ms. | study (animal) |
| S-181 | Rising level is an attention cue, not proof of threat (updates S-10). | study |
| S-12 | Long reverb tails only for awe, wonder, nostalgia; loudness-match dry and wet before judging. | study |
| S-13 | Shepard-Risset loops only for deliberate unease or a countdown, kept short; never as comfort. | study |
| S-14 | Voices and creatures: higher f0, faster, louder = more aroused; low and slow = sad. Direction only. | study |
| S-17 | Rumble = 30-80 Hz harmonics + slow amplitude wobble, not a sub-20 Hz tone. | inference |
| S-20 | Do not encode a spectral-centroid number (no 2018+ evidence). | inference |
| S-21 | After a loud or fast section, give a quiet gap; test 5-20 s in play. (P) | study (small) |
| S-23 | Crisp = energy >2 kHz + attack <5 ms. For crunch try +3 dB overall or 2-8 kHz +3 to +6 dB. (P) | study + inference |
| S-24 | Body of heavy, solid events 60-250 Hz; sell and loot bodies 150-400 Hz. (P) | study + inference |
| S-174 | Store BPM and onsets per second as two fields; change one rhythmic factor per A/B. | inference |
| S-175 | Store spectral frequency and modulation rate as two Hz fields; a 40 Hz roughness rate is not a 40 Hz bass tone. | inference |
| S-177 | For alarm-type nonlinearity use deterministic chaos; frequency jumps, subharmonics or AM alone did not raise alarm. | study |
| S-178 | Register effects can be curved: audition a cue in ≥3 registers at matched loudness. | lead |
| S-179 | Judge intervals with the real instrument's spectrum; consonance ≠ happy, dissonance ≠ fear. | lead |
| S-180 | Non-music sounds: loudness, roughness, sharpness, impulsiveness, fluctuation are arousal dials; set valence by source meaning. | study |
