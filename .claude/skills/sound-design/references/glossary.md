# Glossary

Roblox classes: see `roblox-audio.md` §A. Number tags (M) (X) (O) (=) (P): SKILL.md §4.

| Term | Meaning |
| --- | --- |
| A/B test | Two versions compared blind, loudness-matched |
| Acoustic simulation | Roblox emitter/listener option modelling occlusion, diffraction, reverb |
| Added value, synchresis | Chion: meaning sound lends an image; fusion of simultaneous sound and image into one event |
| Adj. R² | Variance a model explains, corrected for predictor count |
| ADSR, sustain | Attack, decay, sustain, release; sustain is a level, not a time |
| Amplitude modulation (AM) | Periodic level change; 30-150 Hz AM is heard as roughness |
| Angle attenuation | Level change by angle between emitter facing and listener |
| Arousal | Activation or energy, separate from valence |
| Articulation | Staccato (short, detached) vs legato (joined) |
| ASMR | Tingling and calm from close, soft sounds (only some people) |
| Attack | Time from start to peak level |
| Attempt cue | Small, immediate sound on the input, client side; never claims the outcome |
| Auditory icon | Warning that sounds like its meaning |
| AVAS | Required EV warning sound system |
| Binaural | Two-ear recording or rendering keeping 3D cues on headphones |
| Body | Middle impact layer carrying weight (about 40-250 ms) |
| Braam | Long low distorted brass trailer hit |
| BRECVEMA | Juslin's 8 routes from music to emotion: brain-stem reflex, rhythmic entrainment, evaluative conditioning, contagion, visual imagery, episodic memory, musical expectancy, aesthetic judgement |
| Building block (part) | A processed piece in the library (tonal, mechanical, crunch, low body, tail, tick) used to build cues |
| Bus | Group channel with shared volume and effects |
| Cents | 1/100 semitone; PlaybackSpeed = 2^(cents/1200) |
| Check-in A / B / C | Owner listening points: temp pass on the markers / hero options / playable preview solo then full mix |
| Chills (frisson) | Shivers at an emotional peak |
| Cluster, suspension, resolution | Close pitches together; held tone expecting resolution; release of tension |
| Comb filtering | Thin, phasey sound from identical copies a few ms apart |
| Consonance, dissonance | Stable vs tense note combinations |
| Crest factor, headroom | Peak-to-RMS ratio; margin below a ceiling |
| Crossmodal correspondence | Link between senses (small ↔ high pitch) |
| Crunch | Concussive mid layer that sells violence; carries a hit on phone speakers |
| d, r, η², ω², sr², β, tau | Effect sizes: Cohen's d, correlation, variance shares, regression weight, Kendall rank correlation |
| dB, dBA, dBC, dBFS, dBTP, dB SPL | Decibel; A/C-weighted level; level re digital full scale; true peak; pressure at the ear re 20 µPa |
| Decay, tail | Fade after the peak; the late part (reverb, debris) |
| Design pass, edit pass | Making the sounds; then fitting them to the markers in context and dropping what does not serve |
| Deterministic chaos | Irregular noisy source vibration; the nonlinear feature that raised alarm |
| Distance attenuation | Level drop with distance |
| Ducking | Lowering one bus while a more important sound plays |
| EDA, SC, SCR | Electrodermal activity, skin conductance level and responses (arousal markers) |
| Envelope | Level shape over time |
| Equal-loudness contour | Level needed per frequency for equal loudness (ISO 226:2023) |
| f0 | Fundamental frequency (heard pitch) |
| Five layer jobs | Body (weight), tick (contact), crunch (violence), report (space), signature (identity) |
| Foley | Performed action sounds synced to movement |
| Frame | One screen update; 16.7 ms at 60 fps |
| Glissando | Continuous slide between pitches |
| Groove, syncopation | Urge to move; accents against the metre |
| Habituation | Smaller response after repetition; not the same as annoyance |
| Harmonic, partial | Frequency component; harmonics are whole-number multiples of f0 |
| Harmonicity, inharmonicity | How well partials fit one harmonic series |
| HDR audio | Middleware mix: a window follows the loudest sound and drops quieter ones |
| High-pass, low-pass, shelf | Cut below; cut above; tilt one end |
| Hitstop, hitlag | Brief freeze on impact to sell weight |
| HRTF | Direction-dependent ear filtering used for binaural rendering |
| Hysteresis | Different enter and leave thresholds to stop state chatter |
| Infrasound, VLF | Below 20 Hz; very low frequency near the hearing floor |
| Intervals | m2 1 st, M2 2, m3 3, M3 4, 4th 5, tritone 6, 5th 7, m6 8, M6 9, octave 12 |
| IOI | Inter-onset interval between pulse starts |
| ITPRA | Huron: imagination, tension, prediction, reaction, appraisal |
| J-cut | Next scene's audio starts before its picture |
| LDW | Loss disguised as a win |
| LFE, sub-bass | Low-frequency channel; content below about 80-120 Hz |
| LFO | Slow oscillator moving a parameter |
| Looming | Rising level heard as approach |
| LUFS (LKFS), LU, LRA | Programme loudness (BS.1770); loudness unit; loudness range |
| Major, minor, mode | Scale families; Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian |
| Masking | One sound reducing another's audibility |
| Meter, subdivision | Beat grouping; division of a beat |
| Misophonia | Strong negative reaction to sounds such as chewing |
| Missing fundamental | Pitch heard from harmonics without f0 (phones imply bass) |
| Mono sum, mono compatibility | L+R added, as many phones do; how well a mix survives it |
| Near-miss | Result made to look or sound "almost" a win |
| Nonlinear sound | Noise, sudden pitch jumps, chaotic vibration |
| Note-onset density | Audible events per second; not BPM |
| Occlusion, obstruction | Sound fully or partly blocked |
| Onset | Start of an audible event |
| Outcome layer | The big sound (impact weight, reward, celebration) played only on the confirmed result |
| Paid random item | Random outcome bought with Robux or Robux-bought currency |
| Pass-by | Rise-then-fall level (and optional pitch bend) of something moving past the listener |
| Pentatonic | Five-note scale (major: 0, 2, 4, 7, 9 st) |
| Perceived vs induced emotion | Emotion a sound expresses vs emotion the listener feels |
| Pitch ladder | Same sound pitched up step by step over consecutive events |
| PlaybackSpeed | Roblox rate; changes pitch and length together |
| Pre-delay, RT60 | Gap before reverb starts; time for reverb to fall 60 dB |
| Priority, voice cap, voice stealing | Which sounds survive; copy limit; which copy is cut |
| Prosody | Melody, rate and loudness of speech |
| Register | Pitch region |
| Repetition suppression | Smaller brain response to a repeat |
| Report | Echo or reflection layer of a shot that places it in space |
| Reverb, wet/dry | Room reflections; processed vs direct signal |
| Riser | Rising pitch, filter or level building anticipation |
| RMS | Root-mean-square (average energy) level |
| Roughness | Buzzing harshness from 30-150 Hz AM |
| Round-robin, shuffle-bag | Cycling variants; every variant once before any repeat |
| RTPC | Game value driving an audio parameter |
| Safe listening | Limiting level × time dose (adults 80 dB(A), children 75 dB(A), 40 h/week, ITU-T H.872) |
| Semitone (st) | 1/12 octave; ratio 1.0595 |
| Shepard-Risset glissando | Pitch that seems to rise or fall forever |
| Sidechain | One signal controlling a compressor on another (ducking) |
| Signature element | The one recognisable element (usually tonal) of a weapon, ability or character, in every stage |
| Sonic logo | Short brand melody or sound |
| Spectral centroid, flux | Brightness; how fast the spectrum changes |
| Stage sheet | Per action: named stage → event id → attempt or outcome → layers |
| Stand-in | A temporary or improvised source named in the hand-back with its better source |
| Startle | Reflex to a sudden loud sound |
| Stinger | Short musical hit marking an event |
| Sweetener | Extra layer felt, not heard separately |
| Temp pass | Rough sounds on the markers before any polish, to check order and timing |
| Tick | Very short bright contact transient |
| Timbre | Tone colour |
| Transient | Sharp first milliseconds |
| Transient shaper | Processor that boosts or softens the attack; not live in Roblox, so baked |
| Tremolo | Slow AM (Roblox AudioTremolo ≤20 Hz) |
| True peak | Peak including inter-sample peaks (dBTP) |
| Uncertainty vs surprise | How unsure before vs how unexpected the event |
| Valence | Pleasant vs unpleasant |
| Variant | Alternate recording of one cue |
| Vertical layering, horizontal resequencing | Adaptive music by adding aligned stems; by switching sections |
