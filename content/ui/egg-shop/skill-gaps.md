# Skill-book gaps found in the egg-shop test

Severity: **H** changed the result or caused a defect · **M** cost time or needed a judgement call · **L** wording.
"Tripped" = it caused a real error or defect in this run. Note: the lead's rewrite of `ui-figma/references/figma-mcp.md` arrived after the Components page was half built. Of its 8 points, none tripped me (I already used colour-free gradients by script, grid layout after `combineAsVariants`, TEXT + INSTANCE_SWAP properties, a wrapper frame per screen, SVG icons, one mutating call at a time, a node ledger, and the Fredoka assert). The gaps below are **not** covered by that rewrite unless marked.

## Top 5
| # | Sev | File and section | Gap | What I did |
| --- | --- | --- | --- | --- |
| G-06 | H | `ui-design/references/screen-contract.md` §5 vs `ui-design` D-07 + `ui-basics` U-01 | **Contradiction.** §5 maps the 1080 canvas to the phone's *full* short side (f = 0.347). U-01 puts interactive UI in a `CoreUISafeInsets` ScreenGui, which is shorter by the top bar. If the builder fits the canvas into that gui, f ≈ 0.294 and a 128 px button is 37.6 pt (fails 44). No book says which height the outer `UIScale` uses, and the top-bar height is not in the docs mirror. | Designed for f 0.347, kept the top 167 canvas px free of interactive UI, flagged f 0.294 as risk Q2 in spec §9. |
| G-07 | H | `screen-contract.md` §5 (text) and `review.md` check 04 | **Text rubric unusable + outlined text undefined.** "Mobile 18 px at 100 DPI ≈ 4.6 mm" glyph height = ~29 pt = ~85 canvas px; no pet-sim shop can meet it, so every screen is UNVERIFIED forever. No method for contrast of the cartoon signature (white fill + black stroke): fill vs face is 2.7:1 (fail), outline vs face 14.5:1 (pass). | Declared a PROPOSAL rubric (essential ≥ 32 px = 11 pt), measured both fill and outline contrast, asked the owner (Q3). |
| G-08 | H | `ui-style-cartoon` §4 tokens vs `ui-design` D-06 / `ui-figma` F-21 | **Style tokens vanish at phone scale.** Outline 3 px = 1 pt, lip 4 px = 1.4 pt, text 22-24 px = 7.6-8.3 pt on the smallest phone. The book quotes TC values but never converts them, so "thick outline" stops being thick. | Outline 5, halo 10, lip 8/10, text ≥ 30 px; every departure listed in spec §13. Proposal: add a "phone-checked" column to §4. |
| G-02 | H (tripped) | `ui-figma/references/figma-mcp.md` §3 | **`setBoundVariableForPaint` drops paint opacity.** Binding the scrim colour reset opacity to 1, so the 45 %/55 % scrims became solid and hid the whole shop behind every popup. | Bind first, then reassign `{...fills[0], opacity}`. Add this row to §3. |
| G-05 | H (tripped) | `figma-mcp.md` §2 step 3 (components) | **TEXT property defaults are per component set, not per variant.** After `combineAsVariants` all five Odds-row variants said "Bunny 60 %" and the featured `PriceLoading` variant said "99" instead of "…". | Set text with `setProperties` on each instance; in the one variant that must differ, removed the property link and set the text. |
