# Short video plan: <game> · <video id> · <platform> · <date>

Workflow: `marketing-craft` (video). One plan per edit. A native Roblox gameplay video and a social edit are **different deliverables with different rules**: never reuse a voiced social edit as the native video.

**Rule of use.** "First 3 seconds" is a planning field, not a platform threshold. Length, pacing, posting time and frequency are hypotheses unless a cited platform rule sets a limit or this game's own data shows a result. No universal best length, hour or posts-per-day exists in the sources.

## A. Purpose
| Field | Value |
| --- | --- |
| hook | one true tension, surprise, achievement or social moment |
| audience promise | why this viewer would want to **play**, not only watch |
| platform and placement | native Roblox video / YouTube Shorts / TikTok / Reels / other (checked live) |
| objective | awareness / qualified visits / plays / return visits / creator interest |
| build and capture | build version; real play or clearly labelled staging; permissions of anyone shown |
| promise-ledger claim ids | |

## B. Edit
| Field | Value |
| --- | --- |
| first 3 seconds | exact opening image, action, on-screen words, audio cue |
| payoff | the real game event that answers the opening, and its timestamp |
| captions | exact words; placement clear of the platform's buttons and of the game's key UI; languages; reviewed muted |
| sound | game audio / voice / music; music license (library, platforms, paid use, territory, expiry); sound-off read |
| length | candidate duration and the reason |
| call to action | the game's real name and the permitted way to reach it |
| destination | landing surface; share link or campaign key |
| disclosure | sponsor or material-connection label, if any |
| cover frame | an honest, representative frame |
